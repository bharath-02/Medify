# 🏥 Medify - Find & Book Hospitals with Ease

[![Live Demo](https://img.shields.io/badge/Live-Demo-green)](https://medify-three-wine.vercel.app/)
[![Backend API](https://img.shields.io/badge/Backend-Live-blue)](https://medify-mx1r.onrender.com/)

## 🚀 Overview
**Medify** is a full-stack web application that allows users to:
- 🔎 Search for hospitals in the US by **State & City**.
- 🏥 View hospital details, ratings, and emergency services.
- 📅 Book an appointment at their preferred **date & time**.
- 🔐 Secure **authentication (Login/Register)** with JWT.
- 📜 View their **booking history**.
- ⚡ **Fast & Responsive UI** built with Material-UI.

## 🛠️ Tech Stack

### **Frontend:**
- ⚛ **React.js**
- 🎨 **Material-UI (MUI)** for styling
- 🚀 **Axios** for API calls
- 🌍 **React Router** for navigation

### **Backend:**
- 🟢 **Node.js & Express.js**
- 🛢️ **MongoDB (with Mongoose)**
- 🔑 **JWT Authentication**
- 🌐 **CORS & Helmet** for security

### **Hosting:**
- **Frontend**: Vercel
- **Backend**: Render
- **Database**: MongoDB Atlas
